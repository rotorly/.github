# Rotorly

Luftrettung im Flugsimulator. Du fliegst Rettungshubschrauber in Microsoft Flight Simulator 2024 und 2020, eine Leitstelle alarmiert dich, du sprichst über Funk mit ihr und bringst Patienten in die passende Klinik.

- **[rotorly.fly](https://rotorly.fly)**: Livekarte mit allen Hubschraubern in der Luft, Bestenliste und die Leitstelle im Browser
- **Client für Windows**: auf der Website unter "Client herunterladen". Er verbindet Simulator, Tablet im Cockpit und Funk
- **Anmeldung** über Discord, dabei kommst du auf unseren Discord-Server

Der Code ist nicht öffentlich.
